# RouteShare - Лендинг для валидации продукта

Лендинг для проверки гипотезы продукта RouteShare - приложения для создания и обмена уникальными маршрутами по городу.

## 🎯 Цель проекта

Собрать контакты заинтересованных пользователей и оценить спрос на продукт перед разработкой полноценного приложения.

## 📋 Функциональность

- **Hero секция** с ценностным предложением и призывом к действию
- **Описание проблемы и решения** - объяснение ценности продукта
- **Как это работает** - пошаговое описание функционала
- **Преимущества** - ключевые выгоды использования
- **Примеры использования** - сценарии применения
- **Форма сбора контактов** - email, город, интересы
- **FAQ** - ответы на частые вопросы
- **Адаптивный дизайн** - работает на всех устройствах

## 🚀 Запуск проекта

### Локальный запуск

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (с http-server)
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000` в браузере.

### Деплой

#### Vercel
1. Установите Vercel CLI: `npm i -g vercel`
2. В папке проекта выполните: `vercel`
3. Следуйте инструкциям

#### Netlify
1. Перетащите папку проекта в [Netlify Drop](https://app.netlify.com/drop)
2. Или подключите репозиторий GitHub

#### GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите файлы
3. В настройках репозитория включите GitHub Pages

## 📊 Сбор данных

### Текущая реализация

Данные сохраняются в `localStorage` браузера. Для просмотра всех подписок:

1. Откройте консоль браузера (F12)
2. Выполните: `exportSubmissions()`
3. Будет скачан CSV файл со всеми подписками

### Интеграция с backend

Для продакшена замените код в `script.js` (строка ~60) на отправку на ваш сервер:

```javascript
await fetch('https://your-api.com/api/submit', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(formData)
});
```

### Альтернативные решения

- **Firebase** - бесплатный backend для сбора данных
- **Airtable** - таблицы с API для хранения подписок
- **Google Forms** - простой вариант без кода
- **Email сервисы** (Mailchimp, SendGrid) - для email маркетинга

## 📈 Метрики и аналитика

### Рекомендуемые инструменты

1. **Google Analytics** - для отслеживания посетителей
2. **Яндекс.Метрика** - альтернатива для российского рынка
3. **Hotjar / Microsoft Clarity** - heatmaps и записи сессий

### Добавление Google Analytics

Добавьте перед `</head>` в `index.html`:

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>
```
